# Muse Diary

12명의 인물과 관계를 쌓아가는 한국어 비주얼 노벨입니다. 일상 만남과 호감도 이벤트를 진행하고, 캐릭터별 데이트와 계절 이벤트를 즐길 수 있습니다.

## 주요 기능

- 이름을 정하고 새 게임을 시작하는 텍스트 프롤로그
- 장소와 시간대에 따라 달라지는 인물 조우와 대화 선택
- 인물별 일상 에피소드와 호감도 단계별 스토리 이벤트
- 데이트 장소 선택, 대화와 스킨십 반응, 데이트 기록
- 공략 완료 후 캐릭터와 다시 만나는 엔딩 후 데이트
- 봄·여름·가을·겨울 특별 이벤트와 계절의 기억
- 인물 도감, 엔딩 기록, 마이룸과 수집 요소
- 글꼴·본문 크기·표시 속도·효과음 설정
- 진행 상황과 설정의 브라우저 저장

## 실행 방법

Node.js와 npm이 설치된 환경에서 실행합니다.

```bash
npm install
npm run dev
```

Vite가 출력하는 로컬 주소를 브라우저에서 엽니다.

## 명령어

| 명령어 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | TypeScript 검사 후 프로덕션 빌드 |
| `npm run preview` | 프로덕션 빌드 미리보기 |
| `npm run lint` | ESLint 실행 |

## 기술 구성

- React 19, TypeScript, Vite
- Zustand를 이용한 게임 상태 관리
- CSS 애니메이션과 Web Audio API 효과음
- JSON 기반 캐릭터 및 이벤트 데이터

## 프로젝트 구조

```text
src/
├─ components/   공통 화면 요소와 캐릭터 연출
├─ data/         캐릭터, 장소, 이벤트 데이터
├─ engine/       조우, 기록, 텍스트 및 효과음 처리
├─ pages/        타이틀, 홈, 조우, 데이트, 기록, 설정 화면
├─ store/        게임 진행 상태와 저장 처리
└─ styles/       화면 스타일
public/
└─ assets/       배경, 캐릭터, UI 이미지
```

게임 진행 데이터는 브라우저의 로컬 저장소에 저장됩니다.
