## 적용 범위
- 새 게임 START 직후에만 `???` 프롤로그 재생
- 저장된 게임 CONTINUE에는 프롤로그 미재생
- 외부 음원 파일 없음
- 기존 `settings.soundEnabled`를 그대로 사용

## 사운드 방식
`src/engine/soundEngine.ts`의 `playTextBlip()`이 Web Audio API oscillator를 생성합니다.

- square oscillator
- 약 640Hz부터 글자별 소폭 변화
- 약 32ms의 짧은 chirp
- low-pass filter로 날카로움 완화
- 2글자마다 1회 재생
- 공백/문장부호는 무음
- 별도 라이선스/오디오 에셋 불필요

## 조작
- 타이핑 중 화면 탭: 현재 문장을 즉시 모두 표시
- 문장 완료 후 탭: 다음 문장
- `SKIP`: 프롤로그 전체 건너뛰기
- 마지막: `첫 페이지 열기`
