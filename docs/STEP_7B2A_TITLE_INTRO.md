# STEP 7-B2A — 메인 / 인트로 화면 개선

## 이번 범위
- 저장 데이터가 있을 때 `CONTINUE` / `NEW GAME`을 메인 타이틀에서 분리.
- `NEW GAME`은 확인 후 DAY 1 진행으로 초기화하고, 기존 프롤로그를 다시 재생.
- 게임 DAY 기준 계절 표시: 봄(1~24), 여름(25~39), 가을(40~54), 겨울(55~).
- 브라우저 현지 시각 기준으로 작업실 배경을 낮/밤 이미지로 교체.
- 계절별 경량 ambient: 봄 꽃잎 / 여름 보케 / 가을 낙엽 / 겨울 눈.
- 저장 세이브 요약: DAY, 날씨, 발견 인물 수, 완료 루트 수.

## 폰트 방향
현재 본문은 Noto Sans KR, UI는 Pretendard 계열을 유지한다.
S-Core Dream은 공식 설명상 제목용 성격이 강하므로 본문 전체 교체 후보가 아니라 타이틀/강조용 display font 후보로만 구조를 열어 두었다.
`--font-display`의 첫 후보를 `S-Core Dream`으로 지정하되 폰트 파일 자체는 프로젝트에 번들하지 않는다. 설치/웹폰트 연결이 없는 환경에서는 Pretendard → Noto Sans KR 순으로 안전하게 fallback한다.
