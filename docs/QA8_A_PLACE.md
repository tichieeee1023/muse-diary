# QA8-A — DATE SYSTEM / PLACE

이번 빌드는 데이트 최종 시스템을 한 번에 만들지 않고 **A / B / C로 분리하여 검증하는 첫 단계**다.

## 이번 단계에서 한 것

- 데이트의 `PLACE`만 독립 변수로 정리했다.
- 장소 데이터는 아래 정보만 가진다.
  - 장소명 / 부제
  - 배경 이미지
  - 해금 호감도
  - 분위기(mood)
  - 장소 도착 로그
  - DAY에 따라 순환하는 환경 로그 3종
  - 이후 행동 필터링에 사용할 장소 태그(현재 UI에는 노출하지 않음)
- 캐릭터 12명에게 **가장 좋아하는 데이트 장소 전용 한 줄 대사**를 추가했다.
- 기존 QA7의 `선택 → 결과 카드 → RETURN TOUCH` 흐름은 이번 단계 UI에서 제거했다.
- 장소에 입장하면 `배경/캐릭터 비주얼 → 연속 DATE LOG` 형태로만 출력된다.
- 데이트 장면의 배경을 풀스크린 카드로 쓰지 않고, 위쪽의 큰 장소 비주얼 + 아래쪽 로그 종이 영역으로 분리했다.

## 아직 하지 않은 것

이번 단계에서는 의도적으로 아래를 구현하지 않았다.

- DISTANCE
- SAY
- TOUCH
- NEXT 턴 처리
- 데이트용 임시 하트
- 행동 조합 판정
- 역스킨십
- 약점 발견

다음 단계는 **B — DISTANCE** 하나만 붙여서 검증한다.
