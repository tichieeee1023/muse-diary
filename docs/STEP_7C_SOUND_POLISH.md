# STEP 7-C · SFX POLISH

BGM 없이도 화면 전환과 행동의 리듬이 느껴지도록 Web Audio API 기반 효과음을 확장했다.

## 합성 효과음
- tap: 짧은 UI 클릭
- map: 지도 핀 선택
- page: 종이를 넘기는 듯한 노이즈 + 저음
- travel: 장소 이동
- heart: 호감도 선택
- new: 새 기록/새 이벤트
- day: 하루 마감 및 다음 날 전환
- unlock: 장소/업적 해금
- special: 계절 특별 이벤트 완료/진입
- complete: 캐릭터 루트 완료
- rarity-r / sr / ssr: 희귀도별 발견 사운드
- text blip: 프롤로그의 레트로 대사 입력음

모든 소리는 외부 음원 파일 없이 oscillator + filtered noise로 생성한다. 설정의 효과음 ON/OFF를 그대로 따른다.

## 새로 연결한 주요 지점
- 하단 탭 이동
- 지도 핀 선택, 장소 이동
- 오늘의 추천 장소 이동
- 계절 특별 이벤트 진입
- 하루 종료 / NEW DAY
- 이름 확정 후 게임 시작
- BAR 해금
- 업적 해금
- 엔딩/루트 완료

효과음은 BGM 대체가 아니라 입력 피드백과 장면 전환의 빈 공간을 채우는 정도의 낮은 볼륨을 기준으로 설계했다.
