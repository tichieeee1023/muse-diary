# QA17 — DATE SYSTEM FINAL POLISH

마지막 시스템 공사 이후의 1차 통합 마감.

## 적용
- 데이트 장면을 배경 중심의 시네마틱 스테이지로 재배치
- 캐릭터 일러스트를 중앙 카드처럼 두지 않고 우측에 배치해 장소 배경이 보이도록 조정
- SAY / DISTANCE / TOUCH를 데스크톱 3열 선택 패널로 정리, 모바일은 1열
- NEXT 처리 시 캐릭터/배경/응답 카드에 짧은 반응 애니메이션
- 최신 응답으로 자동 스크롤
- DATE MOOD +1/+2뿐 아니라 명확하게 안 맞는 조합은 -1 가능
- 캐릭터별 disliked touch / 경계 반응 추가
- 장소별 1개의 SCENE 이벤트 추가. 새 입력 변수는 만들지 않고 기존 TOUCH 선택지가 상황에 맞게 변형됨
- 장소 특수 행동은 DATE MOOD 보너스 적용
- 기록 메뉴의 DATE MEMORIES에 장소별 제목과 첫 약점 발견 메모 추가
- 누적 DATE LOG 아코디언 구조 유지

## 구조
큰 시스템 추가는 여기서 종료. 이후 작업은 대사, 장소 이벤트, 캐릭터 반응, 밸런스, UI 미세조정 등 콘텐츠 확장을 우선한다.
