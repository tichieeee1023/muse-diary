# STEP 7-B2B — 작업실 메시지

- 첫 만남을 완료한 캐릭터 중 한 명이 DAY마다 교대해 작업실 홈에 짧은 메시지를 보냅니다.
- 같은 DAY에서는 외출 횟수나 낮/밤이 바뀌어도 화자가 바뀌지 않습니다.
- 대사는 호감도 0–39 / 40–79 / 80–99 / 공략 완료의 4단계로 변화합니다.
- 12명 전원에게 단계별 2문장씩 작성해 반복감을 줄였습니다.
- 공략 완료 후에도 메시지가 사라지지 않고 관계가 이어지는 느낌을 유지합니다.
- 메시지는 실제 방문 연출이 아니라 휴대폰에 도착한 짧은 연락으로 처리해 장소 모순을 만들지 않습니다.

- QA 중 `characterFlavor.ts`의 char_004~char_008 기존 매핑이 실제 캐릭터 순서와 어긋난 문제를 발견해, 테마 문구·재회 대사·공략 후 문구를 실제 캐릭터 ID에 맞춰 교정했습니다.
