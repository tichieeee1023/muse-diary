# QA18 — DATE EXPERIENCE UX

## 합의 반영
- 플레이 중 누적 LOG 완전 비노출. 실제 턴 데이터는 내부에서 유지되며 데이트 종료 후 DATE MEMORIES에만 저장된다.
- 장소는 가로형 배너로 분리한다.
- 현재 장소 묘사/환경 묘사는 항상 화면에 노출한다.
- 캐릭터 일러스트는 정사각형 `REC / MOMENT` 프레임 안에 배치한다.
- 한 턴은 ACTION → RESULT → ACTION으로 전환된다.
- RESULT에는 캐릭터 대사, 짧은 행동/반응 서술, DATE MOOD 변화만 즉시 보여준다.
- SAY / DISTANCE / TOUCH는 세로형 접이식 슬롯이다. 한 번에 하나의 슬롯만 펼쳐진다.
- 각 슬롯은 현재 선택값을 항상 요약해서 보여주고, 옵션을 고르면 자동으로 접힌다.
- 중립 기본값을 유지하므로 매 턴 세 항목을 전부 다시 선택할 필요가 없다.
- NEXT/다음 순간 전환 시 REC 프레임으로 자동 스크롤한다.
