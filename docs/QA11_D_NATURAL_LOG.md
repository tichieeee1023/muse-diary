# QA11-D — DATE SYSTEM / Natural LOG

이번 단계는 C에서 확정한 `SAY / DISTANCE / TOUCH` 입력을 바꾸지 않고, `NEXT` 이후의 기록 방식만 다룬다.

## 적용
- 누적 DATE LOG는 기본 닫힘 아코디언으로 이동.
- `NEXT`를 누르면 선택값 이름을 그대로 출력하지 않고 장소별 자연어 행동 로그로 변환.
- PLACE가 SAY / TOUCH 문장 표현에도 개입한다.
- DISTANCE 상태는 이전 단계처럼 다음 턴까지 유지.
