# STEP 7-B0 · Mobile UI QA

이번 패치는 사용자 실플레이 스크린샷에서 확인된 세 가지만 수정합니다.

1. 계절 SPECIAL DAY의 캐릭터 스테이지/완료 카드 일러스트 규격을 4계절 공통 비율로 축소·통일.
2. 스토리 본문과 CTA 간격을 늘리고 `계속 읽기` sticky를 해제해 본문을 가리지 않도록 수정.
3. 지도 범례/안내문을 지도 바깥으로 이동하고, 지도 안 `NEW EVENT`는 작은 `NEW` 배지로 축소.
4. `withJosa()` 유틸을 추가해 `과/와`, `이랑/랑` 등 받침 조사를 자동 처리. 오래된 `{name}이랑`, `{name}와` 형태도 렌더링 시 보정.

아직 새 게임 초기화, DAY 전환 문구, BGM은 건드리지 않았습니다.
