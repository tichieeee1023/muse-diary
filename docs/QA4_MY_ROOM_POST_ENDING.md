# QA4 — My Room post-ending visitors

- 마이룸 방문 풀은 `completedCharacterIds`만 사용한다. 즉, 엔딩을 본 캐릭터만 방문한다.
- 방문 인원은 최대 2명으로 제한했다.
- 엔딩 캐릭터가 2명 이상이면 DAY + 완료 캐릭터 목록을 seed로 두 명을 선택한다. 같은 날 새로고침해도 방문자가 바뀌지 않는다.
- 개인 클릭 대사는 `getMyRoomEndingDialogue()`를 사용해 `complete` 대사만 노출한다.
- 두 명이 동시에 방문하면 `둘이 마주친 날` 크로스토크가 추가된다.
- 크로스토크는 각 캐릭터 성격에 맞춘 가벼운 견제/질투 톤이며, 상대 이름을 직접 언급한다.
- 홈 화면의 일반 작업실 메시지 로직은 기존대로 유지한다.
