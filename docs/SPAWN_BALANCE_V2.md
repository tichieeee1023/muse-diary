# V2 STEP 5-A — 캐릭터 생활권 / 등장 확률 재밸런싱

이 문서는 `characters.json`의 `spawnRules`를 조정한 기준을 기록한다.

## 원칙

- 희귀도(`R / SR / SSR`) 자체의 전역 배율은 유지한다.
- 대표 생활권에서는 해당 캐릭터를 의도적으로 찾을 수 있어야 한다.
- 해금 장소를 열어준 캐릭터는 그 장소에서 체감 가능한 비중으로 다시 등장해야 한다.
- 특정 장소에서 캐릭터 한 명만 보이는 문제는 다음 단계(5-B)의 최근 조우 보정과 함께 해결한다.
- 공략 완료 캐릭터의 등장 감소 역시 5-B에서 처리한다.

## 이번 조정

### 김휘람
- 시립 도서관 낮: `history-floor`뿐 아니라 `window-seat`에서도 등장.
- 도서관 낮 weight `1.4 → 1.5`, 밤 weight `0.8 → 1.0`.
- 편의점: `drink-aisle`뿐 아니라 `window-table`에서도 등장.
- 편의점 weight `1.2 → 1.35`.

목표: 도서관을 대표 생활권으로 확실히 유지하면서, 휘람이 직접 해금하는 편의점에서도 문해준에게 지나치게 밀리지 않게 한다.

### 권재하
- 루프탑: `railing`뿐 아니라 `bench`에서도 등장.
- weight `1.25 → 1.35`.

목표: 루프탑 해금 캐릭터인데 특정 동선에서만 만날 수 있던 제약을 완화한다.

### 유리안
- 대형 쇼핑몰: `popup-floor`뿐 아니라 `living-floor`에서도 낮에 등장.
- 쇼핑몰 weight `0.9 → 1.5`.
- 카페: 눈 오는 날 한정 조건을 제거하고 모든 날씨에서 등장. weight `1.0 → 0.75`.
- BAR weight `0.5 → 0.8`.
- 야시장 weight `1.8 → 2.0`.
- 아쿠아리움 weight `0.65 → 0.9`.

목표: SSR 전역 희귀도는 그대로 두되, 이미 발견한 뒤에는 유리안의 실제 생활권(쇼핑몰 / 야시장 / 조용한 카페 등)을 찾아가면 충분히 다시 만날 수 있게 한다.

## 단순 평균 기준 변화

모든 캐릭터 발견 완료 / 공략 완료 없음 / 직전 캐릭터 없음 상태에서, 각 장소의 유효한 `동선 × 낮밤 × 날씨` 조합을 동일 비중으로 평균한 참고값이다. 실제 플레이 확률은 그날 열린 장소, 선택한 동선, 직전 조우 등에 따라 달라진다.

- 편의점: 문해준 약 `59% → 45%`, 김휘람 약 `17% → 36%`
- 도서관: 김휘람 약 `65% → 76%`
- 대형 쇼핑몰: 유리안 약 `7% → 17%`
- 야시장: 유리안 약 `48% → 50%`
- BAR: 유리안 약 `7% → 10%`
- 아쿠아리움: 유리안 약 `6% → 8%`
- 루프탑: 권재하 약 `5% → 10%`

`SSR` 전역 가중치는 건드리지 않았으므로 진이현의 기존 체감 등장률은 의도적으로 올리지 않았다.


## STEP 5-B — 최근 조우 / 공략 완료 보정

- 최근 조우 캐릭터는 최대 4명까지 순서를 저장합니다.
- 직전 조우 캐릭터는 다른 후보가 있는 동안 후보에서 제외합니다.
- 2번째로 최근 만난 캐릭터는 `×0.38`, 3번째는 `×0.62`, 4번째는 `×0.82`의 가중치 보정을 받습니다.
- 후보가 직전 조우자뿐이라면 완전 제외를 해제해 장소가 막히지 않도록 했습니다.
- 공략 완료 캐릭터는 기본적으로 등장 빈도가 크게 낮아집니다.
  - 현재 장소/시간/날씨에서 아직 보지 않은 DAILY가 남음: `×0.40`
  - 해당 맥락에서 새 DAILY가 없음: `×0.10`
- 따라서 엔딩 캐릭터가 지도에서 사라지지는 않지만, 미공략 캐릭터와 미열람 콘텐츠가 우선됩니다.
- 저장 데이터는 `v12`로 올렸으며 v11 이하 저장은 자동 마이그레이션합니다.
