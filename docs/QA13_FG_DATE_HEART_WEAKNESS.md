# QA13 — F + G / DATE HEART + WEAK POINT

이번 단계는 데이트 시스템의 F와 G만 함께 연결한다.

## F — DATE MOOD HEART

- 본편 호감도와 별개의 데이트 전용 5칸 하트.
- 각 데이트는 `♥♡♡♡♡`에서 시작한다.
- `SAY + TOUCH` 조합을 캐릭터 성향에 맞춰 평가한다.
- 잘 맞는 말 또는 스킨십: +1.
- 말과 스킨십이 동시에 잘 맞음: +2.
- 약점을 정확히 건드림: +2.
- 현재 단계에서는 본편 호감도를 깎지 않으며, 데이트 하트 역시 실패 패널티를 넣지 않는다.
- 상단 `DATE MOOD`에서 결과를 즉시 확인한다.

## G — WEAK POINT + SHY

- 12명 모두 기존 `weakSpot / weakReaction` 데이터를 사용한다.
- 약점 선택지는 처음부터 약점이라고 표시하지 않는다.
- 실제로 약점을 건드린 순간에만 `✦ 예상 밖의 반응`이 나타난다.
- 해당 반응은 캐릭터의 `shy` 일러스트로 전환된다.
- 같은 세션에서 다시 약점을 건드리면 `이미 알아버린 약점`으로 표시한다.
- 누적 DATE LOG에도 약점 반응과 당시 데이트 하트가 함께 남는다.

## 이번 단계에서 하지 않은 것

- RETURN TOUCH
- TOUCH STATE 지속(손을 잡은 상태 유지 등)
- 하트/약점에 따른 다음 선택지 조건부 해금
- 데이트 종료 및 영구 기록 저장
- 약점 발견의 영구 저장

위 요소는 다음 단계에서 따로 연결한다.
