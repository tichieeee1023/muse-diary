# QA9-B — DATE SYSTEM / DISTANCE

이번 단계는 A(PLACE) 다음의 B 단계로, **DISTANCE만 구현**했다.

## 이번에 추가한 것

- 데이트 장면 내부 거리 상태 3단계
  - `space` — 여유 있는 거리
  - `normal` — 자연스러운 거리
  - `close` — 아주 가까운 거리
- 플레이어 입력은 현재 거리 기준 3개만 제공
  - 조금 거리를 둔다
  - 지금 거리를 유지한다
  - 조금 더 가까이 간다
- 거리의 양 끝에서는 더 이동할 수 없는 방향을 비활성화한다.
- `거리 적용` 시 현재 거리 상태가 다음 상태로 바뀐다.
- 변경 결과는 DATE LOG에 `→ 행동` + 장소별 거리 묘사로 누적된다.
- PLACE마다 같은 거리 상태라도 서술이 다르다.
  - 카페: 의자/테이블
  - 서점: 책장/선반
  - 강변: 보폭
  - 수족관: 수조 앞 나란히 서기
  - 전시관: 작품/캡션
  - 밤거리: 걷는 간격
  - 축제: 인파 속 거리
- 거리 상태에 따라 캐릭터 비주얼이 아주 미세하게 확대/축소되어 체감상 가까워지거나 멀어진다.

## 아직 하지 않은 것

- SAY
- TOUCH
- SPECIAL 행동 입력
- 데이트 하트 판정
- 캐릭터 반응 판정
- 표정 변화
- 통합 NEXT 버튼

현재의 `거리 적용` 버튼은 **B 단계 단독 테스트용**이다. 이후 입력 시스템을 합칠 때 `NEXT` 처리 안으로 흡수한다.
