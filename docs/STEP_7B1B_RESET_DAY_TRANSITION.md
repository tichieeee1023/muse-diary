# STEP 7-B1B — 새 게임 초기화 / DAY 전환 정리

## 변경 사항

- 설정의 기존 `수집 기록 전체 초기화`를 `공략 기록만 초기화`로 명확히 구분했습니다. 이 기능은 DAY와 장소 해금을 유지합니다.
- `처음부터 다시 시작`을 추가했습니다. 플레이어 이름과 읽기/효과음 설정만 유지하고 DAY 1, 장소 해금, 방문 기록, 계절 이벤트, 인물/호감도/엔딩 기록을 모두 초기화합니다.
- 계절 SPECIAL DAY는 첫 만남을 완료한 동행 후보가 최소 2명일 때만 홈에 나타납니다. 한 명만 만난 상태에서 봄 이벤트가 즉시 열리는 상황을 막습니다.
- 다음 날 전환 오버레이의 `D + 1` 표기를 제거했습니다. 이제 `NEW DAY / DAY XX / 날씨 · 새로운 하루가 시작되었습니다.`로만 표시됩니다.
