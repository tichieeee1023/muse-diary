# QA15 J — 조건부 데이트 선택지

이번 단계는 **J: 조건부 선택지**만 추가한다. 데이트 종료/기록 저장(K)은 아직 구현하지 않는다.

## 적용 조건

데이트의 선택지는 다음 상태를 읽는다.

- 현재 DATE MOOD 하트
- 현재/이번 턴의 거리
- 현재 이어지고 있는 TOUCH STATE
- 본편 관계 단계(호감도 20~39 / 40~59 / 60+ / 엔딩 완료)
- 해당 캐릭터의 약점을 이번 데이트에서 발견했는지 여부

## 변화

- 초반에는 손잡기/소매 잡기 같은 가벼운 행동 위주로 보인다.
- 관계와 DATE MOOD가 올라가면 머리, 볼, 장난성 스킨십이 단계적으로 열린다.
- 손을 잡은 상태에서 DATE MOOD가 충분히 높아지면 `손깍지를 낀다 ✦`로 행동이 발전한다.
- 높은 관계 + 가까운 거리 + 높은 DATE MOOD에서는 처음부터 `먼저 손깍지를 청한다 ✦`가 열릴 수 있다.
- 발견한 약점이 현재 장소의 행동 풀에 존재하면 `아까 반응이 컸던 곳을 다시 건드린다 ✦`로 다시 나타난다.
- 약점 발견 뒤 장난스러운 SAY는 `아까 반응을 살짝 놀린다 ✦`로 바뀔 수 있다.
- 깊어진 관계와 높은 DATE MOOD에서는 다정한 SAY가 `조금 더 솔직하게 말한다 ✦`로 바뀐다.
- 현재 접촉이 이어지는 동안 낮은 DATE MOOD에서는 갑작스럽게 다른 친밀 스킨십으로 점프하기 어렵게 후보를 좁힌다.

## 상태 연속성 보정

- 손잡기 → 손깍지로 발전한 선택은 실제 TOUCH STATE도 `interlockedHands`로 변경된다.
- 손을 잡고 있다가 다른 접촉으로 옮기면 로그에서 기존 접촉을 잠깐 푸는 흐름을 반영한다.
- 머리/볼/간지럼 같은 순간 접촉은 지속 TOUCH STATE로 남기지 않는다.

## 이번 단계에서 하지 않은 것

- 데이트 종료 턴 수/종료 조건
- DATE LOG 영구 저장
- 다이어리에서 데이트 기록 다시 보기
- 약점 영구 저장

위 항목은 K 단계에서 처리한다.
