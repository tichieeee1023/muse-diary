# QA16 — K: 데이트 종료 + DATE LOG 저장/재열람

## 범위
이번 단계는 K만 구현한다.

- 데이트는 4 TURN으로 마무리된다.
- 4 TURN 이후 장소별 엔딩 문장과 최종 DATE MOOD를 보여준다.
- `오늘의 DATE LOG를 기록한다`를 누르면 실제 플레이 로그를 세이브 데이터에 저장한다.
- 저장된 로그는 하단 `기록` 메뉴의 `DATE MEMORIES`에서 아코디언으로 다시 읽을 수 있다.
- 각 기록에는 DAY / 캐릭터 / 장소 / 최종 하트 / 각 TURN의 행동 로그 / 캐릭터 반응 / 약점 반응 / 역스킨십 / 마무리 문장이 보존된다.
- 본편 호감도나 행동력은 변경하지 않는다.

## 저장
- save key: `muse-diary-save-v13`
- v12 이하 세이브는 자동 마이그레이션
- DATE LOG는 최근 50개까지 보관
- 캐릭터 단독 초기화 시 해당 캐릭터의 데이트 기록도 제거
