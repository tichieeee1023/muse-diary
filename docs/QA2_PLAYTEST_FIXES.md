# QA2 플레이테스트 수정

## 1. 호감도 중요 이벤트 동선 표시
- 현재 장소/시간/날씨/세부 동선에서 실제로 진입 가능한 호감도 이벤트가 있으면 해당 루트 카드에 캐릭터 대표색을 적용합니다.
- 카드 오른쪽에 대표색 포인트 보더를 추가했습니다.
- `EVENT` 라벨과 작은 점멸 dot을 추가했습니다.
- 중요 이벤트가 열린 루트를 선택한 경우 해당 캐릭터를 우선 조우하도록 변경했습니다. 따라서 안내를 보고 올바른 동선을 골랐는데 랜덤 조우로 이벤트를 놓치는 문제를 막습니다.
- 일반 루트의 `ACTION` 번호도 실제 선택지 번호와 일치하도록 수정했습니다.

## 2. 스토리 다음 장면 스크롤
- `계속 읽기`로 다음 SCENE으로 넘어갈 때 새 `story-sheet` 시작점으로 자동 스크롤합니다.
- 이전 화면의 아래쪽 스크롤 위치가 유지되어 새 대사가 화면 위에 생기는 문제를 수정했습니다.

## 3. 다음 날 전환 연출
- 기존 1.4초 길이는 유지했습니다.
- 큰 DAY 숫자 + 큰 날씨 아이콘 + 날씨 텍스트를 한눈에 보이게 재구성했습니다.
- 사선 와이프/라인 모션으로 날짜가 넘어가는 느낌을 강화했습니다.
- 맑음/흐림/비/눈에 따라 날씨 아이콘 포인트 색을 다르게 표시합니다.

## 검증
- 수정한 TSX 2개는 TypeScript transpile 기준 구문 오류 없음 확인.
- CSS 중괄호 개수 일치 확인.
- 패키지 설치가 실행 환경에서 타임아웃되어 전체 `npm run build`는 완료하지 못했습니다.
