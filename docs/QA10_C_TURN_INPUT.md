# QA10-C — DATE SYSTEM / TURN INPUT

이번 단계는 A(PLACE), B(DISTANCE)에 이어 **C: SAY + DISTANCE + TOUCH 입력 조합**만 구현한다.

## 이번 단계에서 추가한 것

- 한 턴의 입력을 `SAY / DISTANCE / TOUCH` 세 그룹으로 통합.
- `SAY`는 현재 `침묵 / 다정함 / 장난` 세 방향만 제공.
- `DISTANCE`는 B에서 만든 `space / normal / close` 상태를 그대로 사용.
- `TOUCH`는 장소별 `touchPool`에서 후보를 가져온다.
- TOUCH 후보는 **이번 턴에 선택한 DISTANCE가 적용된 뒤의 거리**를 기준으로 필터링한다.
  - 예: `normal → 가까이 간다`를 고르면 같은 턴에서 close 전용 TOUCH가 보일 수 있다.
  - 반대로 `close → 거리를 둔다`를 고르면 close 전용 TOUCH는 즉시 사라진다.
- `이 조합으로 기록하기`를 누르면 세 선택이 하나의 TURN 로그로 남고 거리 상태만 실제로 갱신된다.
- 이전 턴의 거리 상태는 다음 턴까지 유지된다.

## 장소별 TOUCH 후보

- 작은 카페: 아무것도 하지 않기 / 손잡기 / 소매 잡기 / 볼 건드리기
- 서점: 아무것도 하지 않기 / 손잡기 / 소매 잡기 / 머리카락 정리
- 강변: 아무것도 하지 않기 / 손잡기 / 소매 잡기 / 어깨에 손 얹기
- 수족관: 아무것도 하지 않기 / 손잡기 / 어깨에 손 얹기 / 머리카락 정리
- 전시관: 아무것도 하지 않기 / 손잡기 / 소매 잡기 / 어깨에 손 얹기
- 늦은 밤거리: 아무것도 하지 않기 / 손잡기 / 소매 잡기 / 어깨에 손 얹기
- 밤의 축제: 아무것도 하지 않기 / 손잡기 / 머리카락 정리 / 볼 건드리기 / 옆구리 찌르기

## 의도적으로 아직 하지 않은 것

- 캐릭터 반응 생성
- 데이트 하트 / 성공 판정
- 캐릭터별 선호도 계산
- 약점 발견
- 표정 변경
- 역스킨십
- 최종 NEXT 연출 및 자연어 LOG 합성
- SPECIAL 입력

즉 QA10-C의 목적은 **플레이어가 한 턴에 무엇을 조작할지와, 세 입력이 한 묶음으로 자연스럽게 느껴지는지 확인하는 것**이다.
