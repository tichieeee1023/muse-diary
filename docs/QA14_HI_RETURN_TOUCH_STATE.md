# QA14 — H + I / RETURN TOUCH + TOUCH STATE

이번 단계는 데이트 시스템의 **H(역스킨십)** 와 **I(스킨십 상태 지속)** 만 구현한다.
J(복합 조건부 선택지)와 K(데이트 종료/저장)는 아직 구현하지 않는다.

## H — 역스킨십

- DATE MOOD가 3 이상으로 올라가는 성공적인 스킨십 순간에, 한 데이트에서 최초 1회 캐릭터가 먼저 접촉을 되돌려준다.
- `RETURN TOUCH` 같은 시스템 라벨은 표시하지 않는다.
- 캐릭터별 기존 후속 행동 문장을 일반 서술 LOG로 자연스럽게 이어 붙인다.
- 너무 먼 거리(`space`)에서는 역스킨십이 발생하지 않는다.

## I — TOUCH STATE

데이트 중 다음 접촉 상태를 기억한다.

- `none` — 접촉 없음
- `holdingHands` — 손을 잡고 있음
- `interlockedHands` — 손깍지를 끼고 있음
- `sleeveHeld` — 소매를 잡고 있음
- `shoulderContact` — 어깨에 손을 얹고 있음

이 상태는 다음 TURN까지 이어진다.

예:

1. 손을 잡는다.
2. 캐릭터가 역으로 손가락을 맞물린다.
3. 다음 TURN 시작 상태는 `손깍지를 끼고 있음`.
4. TOUCH의 `손을 잡는다`는 `맞물린 손을 놓지 않는다`로 문구가 바뀐다.
5. `아무것도 하지 않는다`는 `접촉을 풀고 손을 거둔다`로 바뀐다.

거리 상태가 `space`까지 멀어지면 지속 접촉은 자동으로 해제된다.

## 아직 하지 않은 것

- DATE MOOD / 거리 / 관계 단계 / 약점 발견을 모두 조합한 선택지 잠금과 해금(J)
- 손깍지 이후의 세부 파생 행동을 대량으로 추가하는 것
- 데이트 종료 턴 / DATE RECORD 영구 저장(K)
