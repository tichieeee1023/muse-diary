# QA5 — MY ROOM 엔딩 후 방문 / 2인 대화 확장

## 목적
엔딩 이후 공략 캐릭터를 다시 볼 수 없다는 아쉬움을 `마이룸`에서 해소한다.
마이룸은 공략 진행용 공간이 아니라 **루트 완료 이후의 후일담 공간**으로 취급한다.

## 방문 규칙
- 루트 엔딩을 본 캐릭터만 방문 후보가 된다.
- 완료 캐릭터가 0명: 방문 없음.
- 완료 캐릭터가 1명: 해당 캐릭터 1명 방문.
- 완료 캐릭터가 2명 이상: **매일 정확히 2명만 방문**.
- DAY + 완료 캐릭터 목록을 seed로 사용하므로 같은 날에는 새로고침/재진입해도 같은 두 명이 유지된다.
- 다음 날에는 방문 조합이 달라질 수 있다.

## 대화 구조
### 1. 개인 엔딩 후 대사
선택한 방문자의 `complete` 단계 전용 대사만 사용한다.

### 2. 기본 견제 대사
두 명이 함께 방문하면 각 캐릭터가 상대 이름을 받아 자신의 성격대로 견제하는 범용 대사를 출력한다.

### 3. SPECIAL TALK
12명 전체 조합 `12C2 = 66`쌍에 대해 별도의 조합 대사를 작성했다.
단순히 이름만 바꾼 문장이 아니라 두 캐릭터의 직업, 갭모에, 비설, 관계 방식을 소재로 삼는다.
예: 시간×과거, 보호×귀가, 꿈×마법, 흔적×기억 등.
