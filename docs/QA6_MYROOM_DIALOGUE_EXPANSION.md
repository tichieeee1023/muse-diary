# QA6 — My Room dialogue expansion

## 목적
엔딩 이후에도 공략 완료 캐릭터와 계속 만날 수 있는 마이룸의 텍스트 밀도를 높였다.

## 변경
- 캐릭터별 엔딩 후 개인 대사: 2종 → 4종
- 캐릭터별 범용 견제 대사: 2종 → 4종
- 12인 조합 66쌍 SPECIAL TALK: 각 2종 → 3종
  - 총 SPECIAL TALK 198종
  - 세 번째 대화는 단순 질투뿐 아니라 직업, 비설, 갭모에, 엔딩 후 변화가 드러나는 일상 대화 위주로 추가
- 기존 DAY 기반 순환 방식 유지
- 같은 날의 방문 캐릭터 2명 고정 규칙 유지

## 검증
- `tsc --noEmit` 통과
